      Help & about

      One tap on a stat key records one entry. The scoreboard, the quarter strip, the play-by-play and the box score are all the same list of entries read four different ways, so they can never disagree.

      There is no team-level scoring and no hand-typed score. The only way a number reaches the board is through a player's entry. Team events — timeouts, substitutions, jump balls, technicals — are recorded too, but they are worth nothing.
